Odbiornik zgód
Przykładowa druga biblioteka odbiera stan przy starcie i po każdej zmianie. Tutaj podłącz swój kod przekazujący zgody dalej.
// Uruchom po skrypcie CMP (np. na końcu <body>).
const unsubscribe = DemoCMP.subscribe((consent, reason) => {
  mojaBiblioteka.setConsent(consent);
});
// subscribe od razu przekazuje również aktualny stan.
// unsubscribe() wyłącza nasłuchiwanie.
    

    Konfiguracja i publikacja
    Zapisz plik jako index.html i umieść w katalogu publikowanym przez GitHub Pages. Nie ma kroku budowania. OWATag ładuje zewnętrzny skrypt z ssl.hurra.com.
    Edytuj tablicę VENDORS w źródle, aby zmienić ID, nazwy i opisy vendorów. Po zmianie znaczenia zgód zwiększ CONFIG_VERSION, aby poprosić o nową decyzję.
    API: getConsent(), subscribe(callback), setConsent({google_ads: true}) (pozostałe wartości pozostają bez zmian), acceptAll(), rejectAll(), open() i reset(). Zapis programowy jest jawną decyzją; wywołuj go w odpowiedzi na wybór użytkownika.
    Możesz też nasłuchiwać window.addEventListener('demo-cmp:change', e => console.log(e.detail)). Event obejmuje zmiany; do odczytu stanu na starcie użyj subscribe() lub getConsent().
    Zgody są zapisywane w localStorage dla tego katalogu strony i synchronizowane między kartami. decisionMade: false oznacza brak decyzji, a false u vendora — brak zgody. Reset usuwa zapis i powiadamia odbiorców. Przy niedostępnym zapisie stan działa do odświeżenia.
    

    OWATag (cid=4321) jest ładowany przy każdym wejściu, niezależnie od zgód CMP. Kolejka otrzymuje zdarzenie page_view. Zgody 6024, 6026, 6028, 6030, 6032 i 6034 są synchronizowane przez hc_consent.changeConsents() po udostępnieniu API.
